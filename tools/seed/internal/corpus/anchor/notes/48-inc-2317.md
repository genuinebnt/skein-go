Severity 2. Date 2026-09-26. Duration 23 minutes. Blameless.

## Summary

The metadata cluster changed leader 41 times in 10 minutes. Writes that needed the metadata cluster failed or retried for the duration.

## Root cause

A memory leak in the metrics exporter caused full garbage collection pauses of up to 1.2 seconds on two nodes. Each pause was longer than the 150 to 300 ms election timeout, so followers called elections, the paused node came back with a stale term, and the cycle repeated.

## Fixes

- [x] Fixed the leak and capped exporter memory
- [x] Alert on GC pauses over 100 ms
- [ ] Add pre-vote so a returning node cannot disrupt a healthy leader
- [ ] Chaos scenario: pause a node for 2 s ([[Raft chaos test plan]])

See [[Raft leader election timeouts]] for the timeout settings.
